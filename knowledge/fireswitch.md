# FireSwitch Internship (ValSafe & Zofu)

Tolu worked as a Frontend Development Intern at FireSwitch, where he contributed to two key projects: ValSafe and Zofu.

ValSafe is FireSwitch's incident reporting and safety management platform. Tolu contributed frontend development to the project, including UI work on the onboarding flow, and resolved a CSS image-overlay layout issue in Tailwind CSS on the onboarding screen.

Zofu is an AI tool that tailors resumes to specific job postings to help candidates get past ATS filters. On Zofu, Tolu migrated the project from Next.js to React and connected it to a working backend, building on its existing Supabase integration.
