# PostFlow

PostFlow is a SaaS-style social media content planner live at postflow-up.vercel.app. It features a drag-and-drop scheduling calendar, live post previews, and multi-workspace support, backed by Convex for real-time data management.

Tolu made the Calendar component fully responsive so that it automatically switches to an agenda or list view on mobile devices while preserving touch-based drag-and-drop functionality via a TouchSensor. He also built an in-context reschedule date picker directly inside the post preview modal.
